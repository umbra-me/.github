# umbra-me/.github

Public organisation profile for Umbra. Everything here is published at github.com/umbra-me as soon as it reaches `main`.

## Commands

- Check: `python3 tools/check_profile.py`

## Constraints

- Name only public repositories and released products; never mention private repositories or unannounced work.
- Images in `profile/README.md` use absolute `https://github.com/umbra-me/.github/raw/main/...` URLs; relative paths do not render on organisation pages.
- Keep card and banner SVGs self-contained: system fonts only, no external references or scripts.
- The organisation avatar is uploaded by hand in organisation settings; `profile/assets/umbra-avatar.png` is its source.
- Commit or push only with the owner's authorization.
